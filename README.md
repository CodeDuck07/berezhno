# Бережно — демо-лендинг

Демо-MVP одностраничного сайта о профилактике онкологических заболеваний для девушек и женщин 25+.

## Что внутри

- Интерактивный квиз (вопросы → персональный чек-лист)
- Адаптивная вёрстка (HTML, CSS, JavaScript — `app.js`)
- Без бэкенда — статический сайт

## Как открыть локально

1. Склонируй репозиторий
2. Открой `index.html` в папке `магистратура` (двойной клик в Finder или Live Server)

Или из папки проекта:

```bash
cd "/Users/shanti/Desktop/зерокодер/проекты/магистратура"
python3 -m http.server 8080
```

Затем: http://localhost:8080

Учебный / портфолио-проект. **Не медицинский сервис** — только демонстрация интерфейса и логики квиза. Результаты квиза носят ознакомительный характер и не заменяют консультацию врача.
